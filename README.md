# Single Line: One Stroke Puzzle 🧵

A **one-stroke** puzzle game tailored for **YouTube Playables**, mobile, and desktop browsers. The objective: drag the thread through all lines between brass pins on a felt board, covering every edge exactly once without lifting your finger.

Built on the same tech stack as Block Blast: **Phaser 3 + Vite + TypeScript**. Designed following the `frontend-design` aesthetic rules.

---

## How to Play

- Tap a pin and drag along the dotted lines to stitch the thread.
- **Drag backward** to the previous pin to unpick the most recent stitch.
- **Double lines** (parallel dashed lines) must be traversed twice.
- Control tools:
  - **Undo**: Undo the last move.
  - **Restart**: Clear the board and start fresh.
  - **Hint**: Shows the next valid step. If you reached a dead end, it automatically unwinds back to a solvable state.
- Keyboard shortcuts: `Z` or `Backspace` to undo, `R` to restart, `H` for hints, `Esc` to return to the level select screen.

## 50 Handcrafted & Procedural Levels Across 5 Chapters

Each chapter contains 10 levels and introduces a distinct yarn palette.

| Chapter | Name | Mechanic |
|---|---|---|
| 1 | First Stitch | Levels 1–5 handcrafted (triangle, bow, envelope house…), followed by starter grids |
| 2 | Diagonal Weave | Introduces diagonal connections |
| 3 | Narrow Pathways | Larger boards with complex branching paths |
| 4 | Double Loop | Introduces double-pass edges |
| 5 | Master Tailor | 5×6 complex grids with up to 3 double-pass edges |

- Preconfigured levels reside in `src/levels.ts`, deterministically generated by `scripts/generate-levels.mjs` with a fixed seed.
- Every level is mathematically guaranteed to be solvable via Eulerian path logic.
- Progress auto-saves via YouTube Playables SDK (`ytgame.game.saveData`), falling back to `localStorage` in standalone mode.
- Completing a level **without hints** awards a gold pin indicator on the level select screen.

## Development & Build

```bash
npm install
npm run dev      # Local dev server on http://localhost:3001
npm run build    # Production build into dist/ (ready for YouTube Playables zip upload)
npm run verify   # Verify mathematical solvability & hint recovery for all 50 levels
npm run levels   # Regenerate src/levels.ts from scripts/generate-levels.mjs
```
